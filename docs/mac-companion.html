Mac companion installation and setup

SoundsGood Sync reads a Music library XML export and the audio folders you select, then makes eligible music and playlist information available to the Android app over local Wi-Fi or through a USB transfer folder.

Download and installation status

An official public Mac companion download is not currently available from this site. The inspected companion requires macOS 13 or later. The current build script creates an ad-hoc-signed development app; a reviewed public distribution package, supported architecture information, signing and notarization verification, and an official download link remain to be prepared.

When an approved package is made available, download it only from the official link identified here and follow the instructions supplied for that exact package. A ZIP would need extraction; a disk image would need to be opened before copying the app as instructed. Do not assume either packaging format is available today. Open the installed app normally and follow macOS's security prompts. If macOS rejects the package or the displayed publisher differs from the announced release, stop and contact support; do not disable security protections.

The following setup instructions describe the implemented companion workflow for an already available, trusted copy. They are not a claim that a public release has been distributed.

Prepare your music

  1. Use a Mac running macOS 13 or later and an Android device with the intended SoundsGood edition installed.
  2. In Music on your Mac, choose File → Library → Export Library and save the XML export. The XML describes your library; it does not contain the audio.
  3. In SoundsGood Sync, choose Choose Library XML…, then Choose Audio Folders…. Select folders containing the corresponding downloaded audio files.
  4. Select the playlists to copy, or enable All eligible music. Apple Smart Playlists are copied as their current song lists, not as live Apple playlist rules.

The companion skips unavailable, known protected or cloud-only items and files outside the selected roots. It does not download subscription tracks, remove DRM, convert audio formats or guarantee Android playback of every eligible file. Keep your original music and independent backups.

Transfer over local Wi-Fi

  1. Connect the Mac and Android device to the same trusted local network. Choose the appropriate private Mac address under Choose the local connection.
  2. Review Save a sync report on Desktop. It is enabled by default. Reports can include song titles and artists; Desktop synchronization services may copy them elsewhere according to your settings.
  3. Click Prepare & Start Sharing. After preparation, the Mac displays a pairing code and QR image.
  4. Click Copy Pairing Code and securely transfer it to the Android device. In the intended SoundsGood edition, open Local Sync, paste the pairing link and choose Connect to Mac. A camera can open the QR link if that device supports it. Choose the intended edition if Android presents an app chooser.
  5. Choose an appropriate destination folder, select the music or playlists and review the sync preview. Start the transfer. Use a separate managed destination for each edition.
  6. Check the final Android result. Personal Edition should remain in the foreground during sync; Full supports user-started background sync with progress and cancellation controls. Interrupted work may require reconnecting and reviewing a new preview.
  7. When finished, click Stop Sharing on the Mac. This invalidates the session's old pairing code.

A pairing code grants access to the selected music while sharing is active. Keep it private. The app uses encrypted local TLS and a pinned certificate fingerprint; it does not require opening router ports to the internet.

Transfer using a folder or USB drive

  1. After selecting the XML, audio folders and music, choose Export for USB….
  2. Choose a local folder or attached drive, preferably outside iCloud Drive and other synchronization services. Allow the export to finish.
  3. Make the completed export folder available on Android. In Local Sync → Import from USB or phone storage, choose Choose transfer folder.
  4. Select the folder containing READY, manifest.json and audio, review the preview and import to your selected destination.

The export is a copy containing music and metadata. Protect it like the original library. See the support guide for connection and file-compatibility troubleshooting, and the Full Privacy Policy or Personal Edition Privacy Policy for data handling.
